### <font style="color:#4C16B1;">服务器重构</font>
需要重构网站，首先仿真服务器镜像，然后用 windterm ssh 连接。

![](../../../images/59ff5e5b0a0dd16970bbdf6bf8be87b5.png)

![](../../../images/3bc33735e4caa0fa36b1b2de43d19b75.png)

修改登录密码。成功登入后台。

![](../../../images/70338bcac55392b0daa630b15e998527.png)

接下来恢复数据库。

![](../../../images/eb5ac6a1b626504da79a88505782ef14.png)

宝塔面板可以直接看到数据库密码，先登进去看看。

![](../../../images/4437116d2120cfd98a006fcc0600dc00.png)

检材里面还给了一个 xb 文件，参考这篇文章恢复数据库。

![](../../../images/eb1fddba53789259682b91f2b39ed262.png)

[https://blog.csdn.net/weixin_40230682/article/details/118703478](https://blog.csdn.net/weixin_40230682/article/details/118703478)

安装 qpress。

```shell
wget "http://docs-aliyun.cn-hangzhou.oss.aliyun-inc.com/assets/attach/183466/cn_zh/1608011575185/qpress-11-linux-x64.tar"
tar xvf qpress-11-linux-x64.tar
chmod 775 qpress
cp qpress /usr/bin
```

安装 xtrabackup。

```shell
wget https://www.percona.com/downloads/XtraBackup/Percona-XtraBackup-2.4.9/binary/redhat/7/x86_64/percona-xtrabackup-24-2.4.9-1.el7.x86_64.rpm
yum install -y percona-xtrabackup-24-2.4.9-1.el7.x86_64.rpm
```

使用 xbstream 处理 xb 文件。

```shell
cat hins261244292_data_20230807143325_qp.xb | xbstream -x -v -C /www/server/data
```

进入 /www/server/data 进行解压。

```shell
cd /www/server/data
innobackupex --decompress --remove-original /www/server/data
innobackupex --defaults-file=/etc/my.cnf --apply-log /www/server/data
chown -R mysql:mysql /www/server/data
```

![](../../../images/d17777b784aa0c555938092a072ebfdf.png)

这里报错了，不影响。

去修改 mysql 的配置文件，把所有表名都改成小写。

```shell
vim /etc/my.cnf
#在[mysqld]块下添加
lower_case_table_names=1
```

然后添加 skip-grant-tables，跳过登录验证。

全部完成以后重启 mysql 数据库，然后登入发现数据库恢复成功。

![](../../../images/9d08320f8878c1720e828fc165f86ad1.png)

![](../../../images/0059f0c1bb58fcc512bc74fab35aa5ca.png)

给网站添加一个 ip 作为域名。

![](../../../images/3cdc77e278dfa846509d3271c49a3762.png)

进入网站后发现报错，去修改网站根目录里面的 .env 文件。

![](../../../images/ac91f6c87c2d0ed05cbc6f9832480c23.png)

查看日志，找到后台登录入口。

![](../../../images/09b1cc662275c76d3e814f4691d6dd88.png)

![](../../../images/47b4debe6725a9dd287f4c67d83ff3af.png)

不知道密码，去修改登录逻辑，然后可以任意密码登录。

![](../../../images/dd312adc4264ee3e1fc136eb3ebb03b0.png)
